# fostd-pages

Опубликованная сборка игры [PRISM FORGE](https://github.com/fosemberg/fostd).

**Играть:** https://fosemberg.github.io/fostd-pages/

## Что здесь

```
docs/          собранный клиент — то, что раздаёт GitHub Pages
  index.html
  assets/      бандл и стили с хешами в именах
  .nojekyll    чтобы Jekyll не съел папки, начинающиеся с подчёркивания
```

Исходники живут в отдельном репозитории — [fosemberg/fostd](https://github.com/fosemberg/fostd).
Здесь лежит только результат сборки.

## Как обновить

В репозитории с исходниками:

```bash
npm run build:pages          # собирает с относительными путями
cp -r dist/* ../fostd-pages/docs/
```

`build:pages` отличается от обычной сборки флагом `--base=./`: GitHub Pages
раздаёт проект из подкаталога `/fostd-pages/`, и абсолютные пути к ассетам там
не найдутся.

## Настройка GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка
**`/docs`**.

## Что игра умеет без сервера

Всё. Клиент — статические файлы, которые работают офлайн после первой загрузки.
Игра вдвоём тоже не требует сервера: браузеры соединяются напрямую через WebRTC,
а описания сессий игроки передают друг другу коротким кодом — любым
мессенджером. Публичные STUN-серверы нужны только чтобы узнать собственный
внешний адрес, и их можно выключить в настройках.
